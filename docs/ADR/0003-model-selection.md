# ADR 0003 — Выбор модели для дистрибутива

Статус: **открыто** · 2026-10-09

Кандидаты (закреплены в `tools/ci/pins.json`): Qwen3.5-9B Q6_K (AtomicChat, 7,36 ГБ) и Qwen3-14B Q5_K_M (официальный Qwen, 10,5 ГБ). Обе Apache-2.0 (базовые модели); провенанс сторонней квантизации 9B — на аудит Astra; запасные источники той же квантизации: unsloth, bartowski, lmstudio-community.

Разведка (10 фраз): обе работают на CPU, рассуждения отключаются, RSS 7,1 / 10,8 ГБ, генерация 3,7 / 2,3 ток/с на 2-ядерном CI-сервере. По фразам: 14B точнее в лексике (خصصت vs ошибочное أصدرت у 9B; без добавленной модальности), у обеих есть грамматические ошибки согласования в арабском.

Решение принимается по процедуре `docs/EVAL_RUBRIC.md` §5 после прогона 400 кейсов (workflow `bench`). До экспертной оценки решение будет помечено как временное.
