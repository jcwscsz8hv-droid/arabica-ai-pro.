# ADR 0001 — Стек приложения

Статус: принято (Claude), ожидает аудита Astra · 2026-10-09

**Решение.** Python 3.12 + PySide6 (Qt 6) для GUI; llama.cpp (`llama-server`, официальная Windows CPU-сборка) как движок; SQLite для словаря/истории; PyInstaller onedir → Inno Setup с `DiskSpanning=yes`, `DiskSliceSize=1800000000`.

**Почему.** Совпадает с утверждённой архитектурой ТЗ; не требует WebView2/Docker/WSL/Python на целевом ПК; Qt даёт нативный bidi/RTL; официальная сборка llama.cpp содержит набор CPU-бэкендов (x64, sse42 … zen4) с выбором при запуске — это снимает неизвестность CPU без собственной компиляции.

**Отвергнуто.** llama-cpp-python (нужна компиляция под Windows, отставание поддержки новых архитектур, в т. ч. Qwen3.5); Tauri/Electron (WebView2/Chromium, больше поверхность атаки); собственная сборка llama.cpp (без выгоды на этапе 1.0).

**Последствия.** Python-рантайм и Qt входят в дистрибутив (~250 МБ); модель — отдельный файл GGUF в `models/` с `manifest.json` (SHA-256 проверяется при первом запуске).
