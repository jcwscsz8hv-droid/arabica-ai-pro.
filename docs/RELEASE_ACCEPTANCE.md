# Невыпускаемые условия («release gates») Arabica AI Pro 1.0

## Обязательные требования

- [ ] 64-bit Windows 10 1809+ чистая машина, подтверждённое CPU/GPU; бинарная совместимость проверена.
- [ ] Полностью установленное приложение: PySide6 + Python runtime + llama.cpp + настоящие GGUF-веса, все лицензии и нужные библиотеки в комплекте.
- [ ] Реальный перевод RU→MSA и MSA→RU на машине, **не имеющей доступа к интернету**, с отключённым сетевым адаптером.
- [ ] Отсутствуют запросы на логин, установку Python, Visual C++, драйверов, Google API, загрузку модели, update/telemetry.
- [ ] Реальные параметры модели, чат-шаблона и SHA256 задокументированы; GGUF checksum verified.
- [ ] Все файлы `setup*.bin` менее 2GiB, вместе с `setup.exe` находятся в одном каталоге, могут быть скопированы через iPhone и exFAT USB.
- [ ] Все publish assets есть в release, SHA256SUMS и manifest.json корректны; тест повреждённого одного файла выдаёт понятную ошибку.
- [ ] Windows paths с пробелами и кириллицей обрабатываются, арабский RTL корректен, русский LTR корректен.
- [ ] На долгих переводах GUI не зависает, отмена работает, контекст и термины сохраняются.
- [ ] Без интернета доступны сохранение истории, локальные глоссарии, импорт/экспорт TXT/DOCX.
- [ ] Проведены лингвистические слепые тесты, результаты и типовые ошибки опубликованы честно. Никаких необоснованных сравнений с Google.
- [ ] CPU совместимость с AVX2 / без AVX2 проверена или документировано, что без AVX2 запуск невозможен и пользовательское железо требует проверки.
- [ ] Нужное свободное место определено; установщик предупреждает до распаковки, временное место проверено.
- [ ] Обеспечено отсутствие выхода наружу (no external connections), нет доступа к закрытым данным вне профиля без согласия.
- [ ] После reboot и полного uninstall приложение ведёт себя корректно; пользовательские данные не удаляются без согласия.

## Блокеры

- Приложение — лишь HTML-прототип, содержит пустые фейковые ответы, вызывает веб-API или скачивает модель после установки.
- Модель не помещается в память или не запускается на CPU-only тестовой машине.
- Некорректные `/think` шаблоны; модель выдаёт объяснения вместо перевода по умолчанию.
- Пропущенные части установщика; ни один реальный офлайн-смоук тест не выполнен.
- Нет проверки лицензионных требований к модели/бинарям/квантам.

## Примеры критериев доказанности

Каждый пункт выше сопровождается test log, hash, screenshot или ссылкой на job/build artifact. Отчёты со статусом «untested» не засчитываются как «passed». Если физического чистого ПК нет — финальный release gate остаётся НЕ ПРОЙДЕН.
