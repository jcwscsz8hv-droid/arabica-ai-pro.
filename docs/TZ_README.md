# Arabica AI Pro — комплект разработки Claude + Astra

**Редакция:** 9 октября 2026 года. **Состояние:** ТЗ готово; кода, обученной собственной модели и готового Windows-установщика в этом архиве **нет**.

## Команда

- **Claude — ведущий разработчик и лингвистический инженер.** Создаёт репозиторий, код, локальную переводческую систему, словарь, GUI, автоматические тесты, Windows-сборку и полный офлайн-установщик со встроенной моделью. Не ограничивается концепцией или прототипом.
- **Astra — системный архитектор и независимый технический аудитор.** Проверяет гипотезы о моделях, Windows/CPU-совместимость, архитектурные решения, безопасность, воспроизводимость сборки и отчётность тестов. Составляет замечания с критичностью и проверяет исправления Claude.
- **GPT-6 (ChatGPT) — координация, подготовка требований, приёмка, аудит переводческих кейсов.** Сводит результаты и вырабатывает задания на исправления. Не выдаёт чужие тестовые заявления за доказанные.

## Порядок действий

1. Передать Claude `TECHNICAL_SPEC.md`, `CLAUDE_TASK.md`, `BENCHMARK_PLAN.md`, `RELEASE_ACCEPTANCE.md`.
2. Передать Astra `TECHNICAL_SPEC.md`, `ASTRA_TASK.md`, `BENCHMARK_PLAN.md`, `RELEASE_ACCEPTANCE.md`.
3. Astra выпускает архитектурное ревью кандидатов на роль переводческого движка; Claude готовит проверяемый прототип реального CPU-перевода и схему измерений. Кандидат Qwen3.5-9B Q6_K — гипотеза, не принятый победитель.
4. После фиксации ADR Claude реализует основные функции и тесты. Astra проводит независимый аудит кода/конфигурации/сборки, выдаёт конкретные исправления. Claude устраняет блокирующие проблемы.
5. Claude собирает полную Windows-дистрибуцию, включая веса модели, все зависимости и многофайловый установщик с контрольными суммами. Astra проверяет воспроизводимость и отчётность тестов.
6. Финальный релиз возможен **только** после реальной установки и двустороннего перевода на чистом Windows 10 без подключения к сети. Если сборка или проверка недоступны, честно пометить этап блокированным.

## Неизменяемые требования

- Целевой ПК: Windows 10 x64, 40 ГБ ОЗУ, свободно 30–100 ГБ, CPU/GPU неизвестны. Нужен корректный fallback CPU-only.
- Перевод строго **русский ↔ современный стандартный литературный арабский (MSA / фусха)**; никаких арабских диалектов.
- Работа после установки без сети, учётных записей и облачных API; никаких Google Translate/TranslateGemma.
- Скачивание только на iPhone, перенос через адаптер и USB-носитель. Весь установочный комплект доступен как файлы по частям для переноса.
- В финальном релизе действительно включены модельные веса, переводческий движок, необходимые runtime-библиотеки, офлайн-лицензии, инструкции и SHA-256.
- Не заявлять превосходство над сторонними переводчиками без слепых сравнительных тестов.

## Документы

- `TECHNICAL_SPEC.md` — единые функциональные/системные требования.
- `CLAUDE_TASK.md` — полная реализация, лингвистика, модели, GUI, сборка и выпуск.
- `ASTRA_TASK.md` — системная архитектура, внешний аудит и проверки.
- `BENCHMARK_PLAN.md` — методика сравнения локальных моделей.
- `RELEASE_ACCEPTANCE.md` — критерии готовности к автономной установке.

**Важно:** Этот архив содержит только задания и технические материалы. Программа с включёнными нейросетями ещё не создана.
