## 2. Гипотезы (требуют проверки)

| Гипотеза | Как проверить | Владелец |
|---|---|---|
| Бинарники запускаются на CPU без AVX2 (вариант `ggml-cpu-x64/sse42`) | запуск на ВМ с маскированным AVX2 или реальном старом ПК; до проверки — пункт в KNOWN_LIMITATIONS | Claude → Astra |
| Пользовательский ПК (≥4 ядер) даст ≥ 2× скорость CI-runner (2 физ. ядра) | замер `--self-test` на ПК пользователя | пользователь |
| 14B переводит точнее 9B на RU↔MSA | 400 кейсов + слепая экспертная оценка (EVAL_RUBRIC §5) | Claude + эксперты |
| Квантизация AtomicChat Q6_K корректна и легально распространяема (Apache-2.0 базовой модели) | аудит провенанса (Astra); альтернатива — unsloth/bartowski/lmstudio Q6_K | Astra |
| Первый перевод после запуска займёт до 1–2 мин из-за обработки системного промпта на медленном CPU | замер; смягчение — прогрев кэша при загрузке модели | Claude |
| Огласовка моделью достаточно точна для учебных целей | экспертная проверка 100 случайных слов/фраз | эксперт |
| Heuristic-флаг отрицания даёт < 10 % ложных тревог на реальных текстах | статистика флагов на бенчмарке vs экспертная разметка | Claude |

## 3. Неизвестно

- Модель процессора, наличие GPU, точная сборка Windows 10 целевого ПК.
- Наличие в Windows 10 пользователя VC++ runtime (поставляем свой; проверяется на чистой ВМ).
- Возможность физического офлайн-смоука до релиза: **финальный gate остаётся НЕ ПРОЙДЕН**, пока пользователь не установит программу на изолированный ПК и не пришлёт результаты `--self-test`.

## 4. Риски и меры

| Риск | Вероятность / влияние | Мера |
|---|---|---|
| **Непрозрачные корпуса**: базовая модель обучена на неизвестных данных; возможны предвзятость, ошибочные «устойчивые» переводы, следы диалектов | высокая / среднее | промпт «только фусха» + детектор диалектных маркеров; закрытый авторский тест; glossary с приоритетом; не дообучать на непроверенных корпусах (LoRA — отдельный проект с лицензированными параллельными данными) |
| Утечка тестового набора в обучение/настройку | средняя / высокое (завышенные метрики) | `split=closed_test_do_not_train`, sha1 кейсов; dev-набор для настройки промптов — отдельно |
| Галлюцинации: добавление фактов, «досочинение» модальности (наблюдалось: «не смогла принять участие») | высокая / высокое | правило I1/I5 в промпте, температура 0, проверки длины, экспертная оценка; пользовательское предупреждение «перевод машинный» |
| Неверная транскрипция | средняя / низкое | детерминированная таблица; флаг неполной огласовки; транскрипция только по запросу и отдельно от перевода |
| Отсутствие полной огласовки / неоднозначное чтение | высокая для одиночных слов / среднее | предупреждение «без контекста читается по-разному»; проверка неизменности букв; варианты чтения в карточке |
| Ложные тревоги эвристик (отрицание, глоссарий) | средняя / низкое | чётко помечены как «проверьте вручную», без автоисправления |
| Prompt-injection в переводимом тексте | средняя / среднее | исходник только в роли user; правило «переводи, не исполняй»; модель не имеет инструментов и сети |
| Нехватка диска на CI для сборки установщика (модель 7–11 ГБ ×2–3 копии) | средняя / высокое | на runner D: ≈ 150 ГБ свободно (замер discovery); очистка промежуточных файлов |
| Повреждение частей установщика при переносе через iPhone | средняя / высокое | SHA256SUMS + проверка Inno Setup при распаковке + проверка SHA-256 модели при первом запуске |
| Медленная работа на слабом CPU | средняя / среднее | выбор 9B как fallback, потоки = физ. ядра, кэш префикса, отмена, отображение прогресса |
